# 历史实验归档

本目录于 2026-09-20 收录已有的 205 份 JSON 报告，覆盖桌面场景、近似物理回放、示教接近路径、协议回放、Transformer 训练/量化与数字孪生评测。它是历史成果归档，不是本轮重新运行 205 次实验。

- `pi_simulations/`：Pi 工程的离线场景、协议、流程与运动学回放；
- `pi_decision/`：策略训练、回放、留出集和量化报告；
- `pi_final_verification/`：2026-08-16 的离线复验结果；
- `digital_twin/`：过程图 Transformer、扩散候选和多观测评测。

`MANIFEST.json` 逐文件记录源内容 SHA-256、公开副本 SHA-256 和字节数。公开副本将本地绝对路径转换为仓库路径或通用资产名，其他可解析结构和数值不变。各报告原有失败、拒绝、接触、适用范围字段均保留。

模型权重和合成数据集作为 Release 附件提供；清单中的 `stored_as` 将重复别名指向实际保存的文件。未解析成功的控制台日志在清单 `excluded` 中列出。
