# 小U表情外观与 Control Tower 协作

小U保留两套原有外观表现：全屏 GIF 表情屏用于真实设备展示；Canvas 动画表情用于桌面窗口中的精细预览。语音、视觉、对话仍通过共享 `face_state.json` 驱动全屏表情，Control Tower 不会覆盖这个实时状态。

## Control Tower 中的表情交互

- **实时表情**是默认模式：嵌入式动画读取当前共享状态，语音倾听、思考、搜索、找到目标、回答、报错等原有表情会原样显示。
- **任务表情预览**只在 Control Tower 的嵌入式动画内生效，不写 `face_state.json`。它把安全状态翻译成可理解的情绪：J5 数据过期为“困惑并等待反馈”、关节 offline 为“疑问”、安全门未就绪为“暂停提醒”、仿真观察为“思考”。
- 原有全屏表情屏、对话情绪桥、GIF 资源和启动脚本都不替换、不删除；它们仍是实体小U外观的权威呈现。

## 外观质量规则

1. 错误、暂停、offline、stale 必须同时有清晰文字原因，表情只是辅助，不以卖萌掩盖问题。
2. 正常观察/思考保持克制；搜索和规划才显示专注；成功后短暂开心，随后回到待机。
3. 表情映射、GIF 和 Canvas 状态必须双向可用。离线审计检查所有状态映射、GIF 帧、对话 emote、Control Tower 集成点和便携启动脚本。
4. Pi 部署包完整携带 GIF、表情桥、两种显示器实现和 Pillow 依赖；归档 manifest 会校验每个文件。该扩展只增加界面内存预算，仍不含任何硬件执行入口。
