# 树莓派离线推理包：可验证安装与原子回滚

该包只包含 ONNX 推理、只读诊断、状态面板和硬件锁配置；不含 PyTorch、训练集、MuJoCo、控制器启动或任何执行入口。安装工具从不打开串口/CAN，也不启动 ROS2/MoveIt。

## 交付结构

- `DEPLOYMENT_MANIFEST.json`：每个已交付文件的 SHA-256；释放前和释放后都必须校验。
- `scripts/verify_pi_inference_release.sh`：检查 manifest、模型、必需脚本、运行时依赖和硬件锁；不接触设备。
- `scripts/install_pi_inference_release.sh`：先解压到独立临时目录、完成 manifest 校验，再按 digest 创建不可覆盖的 release 目录。
- `scripts/setup_pi_inference_env.sh`：在 `~/xiaou_releases/.venv_inference` 建独立推理环境并安装 ONNX/Pillow；不修改系统 Python。其余表情与状态面板脚本会优先使用此环境。
- `current` / `previous`：两个原子 symlink。激活只切换 `current`；回滚只把 `current` 指回 `previous`，不删除历史 release。

## 安全规则

1. 必须由外部渠道记录并人工提供压缩包 SHA-256；工具拒绝隐式信任压缩包。
2. 每次安装先做 staged verify。任何 hash、依赖、必需文件或 `motion_enabled=false` 检查失败，均不会激活版本。
3. `--activate` 只意味着切换推理/界面文件版本，不改变硬件锁；新版本仍需单独通过只读验证。
4. 一旦启动后发现模型、依赖或界面回归，使用 `--rollback` 恢复上一个完整 release；不要手工覆盖 `current` 目录。

## 验收证据

保存：归档 SHA-256、`DEPLOYMENT_MANIFEST.json`、安装输出、release 路径、验证 JSON、Pi 实测 RSS/FPS/温度，以及硬件锁仍关闭的配置快照。2GB 内存预算只能作为部署前筛选，不能替代实测。
