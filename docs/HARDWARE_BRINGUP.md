# 硬件上机与联调边界

本页描述硬件回来后的顺序，不提供默认运动命令。所有实际动作都应由现场操作者在可触及急停、限位和空载空间下执行。

## 1. 先确认物理条件

- 固定机械臂、桌面、相机与线束；
- 确认电源、电机 CAN、Pi–F407 UART 的接线和共地；
- 确认急停可用，并清空机械臂周围障碍物；
- 记录每个关节节点 ID、方向、零位、物理限位和允许速度。

## 2. 只读通信

先做 PING、单关节反馈和标定状态读取。目标是确认帧格式、序号、回包时延、六轴反馈完整性和时间戳，而不是让任何关节移动。

如果单个关节偶发超时，应记录发生轴、序号、请求时间、回复时间和控制器状态。不要把一次成功回包当作连续健康证据。

## 3. 标定与预览

分别采集零位、ready 位、相机标定和受限工作空间。然后运行离线 IK、示教路点预览与 ROS 2 review-only 启动，核对坐标方向和预抓路径。

提交中的 `hardware_calibration.json` 是锁定配置。现场标定结果应保存在未提交的设备配置中，并保留可追溯的测量记录。

## 4. 执行前条件

真实执行工具要求显式确认、完整关节回读和固件状态。遇到 ACK 不确定、反馈超时、急停、未知标定或超限时，工具应停止进一步下发，并报告 STOP 是否被确认。

这不是为了替代现场判断，而是为了让“没有得到确认”在软件中可见且可追溯。
