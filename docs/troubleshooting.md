# 故障排查

## UART 超时

先确认设备路径、波特率和 8N1 设置，再做单帧 PING。连续超时应停止轨迹入口，保存原始日志，检查 TX/RX 交叉、共地、F407 复位状态和串口占用。不要通过放宽超时把未知状态当成成功。

## J5/J6 反馈不稳定

反馈必须同时满足序号匹配、时间新鲜度和关节 ID 校验。J5 偶发超时或 J6 离线时，诊断工具应报告缺失轴并保持运动锁定；不要用上一帧角度填充当前反馈。

## 标定或规划被拒绝

检查相机分辨率、homography 输出帧/单位、目标类别白名单、工作空间边界和对象抓取配置。规划预览成功不代表已获得真实运动授权。

## ROS 2 / MoveIt

先运行 dry-run 节点和消息契约测试。若目标系统未安装 ROS 2/MoveIt，使用仓库内纯 Python 回放验证数据流，不把未启动的节点写成已验收能力。

## 收集诊断包

保留命令行、时间戳、固件版本、配置哈希和原始 UART 日志；删去密码、令牌和站点私有配置后再提交 Issue。
