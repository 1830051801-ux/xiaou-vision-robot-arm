## 9. 硬件回来后的必做验收

离线通过不等于真实机械臂通过。硬件回来后仍须按顺序完成：

1. 保持动作锁，执行硬件预检与 UART PING/只读六轴查询。
2. 实测 J5/J6 连续反馈新鲜度、丢帧率、编码器方向、零位和扭矩/电流。
3. CAN 先被动监听，再确认节点 ID、1 Mbps 实际配置、急停和 MCU 标定指纹。
4. 采集真实相机标定、杯子/纸巾数据，重新训练并验证 YOLO。
5. 树莓派实测单进程/全链 RSS、FPS、温度、降频和长时间稳定性。
6. 只有急停、限位、反馈和标定全部通过后，才进入单轴低速、空载六轴、软物体和实物抓取回归。
