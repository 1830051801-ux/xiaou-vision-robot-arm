# 六轴机械臂算法验收与实机前置条件

更新时间：2026-08-05

## 当前结论

当前版本已完成六轴机械臂的离线数学核心、2D 视觉坐标链、MoveIt 2 规划链和多层运动门禁。它可以用于离线 FK/IK、轨迹生成、模型检查和 ROS2 规划集成，但尚未满足真实机械臂运动条件。

禁止把“离线算法通过”等同于“实机已可运动”。树莓派 ROS2 构建、六个关节标定、CAN 反馈、急停、扩展相机标定和每类物品抓取高度仍需现场验证。

## 数据流

```text
2D camera image
  -> YOLO class and pixel center/orientation
  -> calibrated pixel-to-base XY homography
  -> measured table Z + fixed per-class grasp height
  -> base_link PoseStamped
  -> MoveIt 2 IK, self-collision and environment planning
  -> planned trajectory topic
  -> future calibrated six-axis hardware bridge
```

VLA 或 Transformer 只能位于任务理解和目标选择层，输出受约束的物品类别、抓取意图或候选目标。它不能直接生成并发送关节/CAN 命令，也不能绕过标定、MoveIt 碰撞检查和硬件门禁。

## 2D 相机的固定 Z

文件：`robot_ai/arm_control/config/object_grasp_profiles.json`

每一类保存一个相对桌面的固定 TCP 抓取高度，单位为米：

```json
"grasp_height_m_by_class": {
  "pen": null,
  "cup": null,
  "cola": null,
  "bottle": null,
  "earphone": null
}
```

用实际物品和夹爪逐类测量后，把对应 `null` 改成实测值。算法使用：

```text
target_z_m = measured_table_z_m + grasp_height_m_by_class[target_class]
```

类别没有有效高度时，感知节点只发布 `configuration_incomplete`，不发布目标姿态。

## 已实现的算法保护

- POE 正运动学和 Space Jacobian。
- 阻尼数值 IK，带刚体变换检查、有限值检查、实测关节限位、单步上限和回溯收敛。
- 五次时间缩放关节轨迹，按每轴速度和加速度限制自动计算持续时间。
- 目标必须属于 `base_link`，具有非零新鲜时间戳、有限位置和单位四元数。
- 目标中心必须位于相机标定像素凸包内，并连续多帧稳定。
- 旧运动入口已删除；六轴执行只允许从 ROS2/MoveIt 安全门进入。
- CAN 工具只接收，不包含发送调用。
- ROS2 规划节点和 `move_group` 同时禁用轨迹执行。

## 真实运动解锁条件

文件：`robot_ai/arm_control/config/hardware_calibration.json`

以下内容全部必须来自单轴、低速、小角度、有人控制急停的现场标定：

- CAN 接口和实测波特率；
- 六个唯一关节 ID；
- 六轴编码器零位和方向；
- 六轴位置、速度、加速度限制；
- 厂家协议实机确认；
- 急停链验证；
- 六轴反馈链验证。

全部有效后仍需人工把 `motion_enabled` 改为 `true`。当前配置保持 `false`。

## 离线复验

在项目根目录运行：

```powershell
python -m unittest discover -s tests -v
python tools/verify_six_axis_stack.py
python -m compileall -q robot_ai ros2_ws/src
```

验收报告：`runtime/arm_model_checks/six_axis_verification.json`

## 树莓派 ROS2 构建

树莓派在线后先确认发行版：

```bash
echo "$ROS_DISTRO"
ls /opt/ros
```

然后在树莓派项目目录构建：

```bash
cd ~/raspi_robot_ai/ros2_ws
source /opt/ros/$ROS_DISTRO/setup.bash
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```

只启动规划链，不执行真实运动：

```bash
ros2 launch xiaou_arm_planning pipeline.launch.py \
  project_root:=/home/pi/raspi_robot_ai \
  image_topic:=/camera/image_raw \
  target_class:=pen \
  table_z_m:=MEASURED_TABLE_Z_METERS
```

此启动文件仍强制 `allow_execution=false` 和 `allow_trajectory_execution=false`。
